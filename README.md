# Portafolio Técnico - Sergio Galindo

Este repositorio contiene una selección de proyectos desarrollados durante mi formación profesional, enfocados en áreas clave para la innovación tecnológica y la eficiencia operativa.

Proyectos Destacados

1. Big Data & Análisis Predictivo (Incendios SEMARNAT)
* **Descripción:** Procesamiento y análisis de grandes volúmenes de datos históricos.
* **Stack:** Python, PySpark, MongoDB.
* **Impacto:** Extracción de patrones críticos para la toma de decisiones basada en datos masivos.

2. Sistemas Distribuidos (Procesamiento de 100 Libros)
* **Descripción:** Implementación de algoritmos para el procesamiento paralelo de información.
* **Stack:** Python, PySpark.
* **Impacto:** Optimización de tiempos de ejecución mediante computación distribuida.

3. Infraestructura y Redes (Casos: Samsung / Calzzapato)
* **Descripción:** Diseño y simulación de arquitecturas de red corporativas.
* **Stack:** Cisco Packet Tracer.
* **Impacto:** Aseguramiento de la conectividad y escalabilidad en entornos empresariales de alto tráfico.
